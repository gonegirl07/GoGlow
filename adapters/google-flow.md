# Google Flow adapter notes

Status: planning only; no live integration implemented.

Before automation, verify whether an officially supported API or permitted integration exists for the required actions. A web UI does not prove API availability.

For manual runs record exact model label, mode/settings, aspect ratio/duration controls, reference assets and their roles, first/last frame or extension behavior actually used, output asset location and duration, failures, and revisions.

Never store browser cookies, session tokens, or credentials in this repository.
