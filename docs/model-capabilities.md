# Model capability register

The labels “Omni 1.1 Flash” (video) and “Nano Banana Pro 2.1” (image) are user-provided working labels, not independently verified current UI labels. Confirm exact names and options in the live Flow selector before recording a run.

For each model/tool record:
- Exact displayed name and product surface
- Date checked
- Role and input/output types
- Aspect-ratio and duration controls
- Reference-image and extension behavior
- Camera/motion controls
- API/automation support and official evidence
- Known limits and reproducible failure cases

Prefer official current documentation and live UI evidence. Distinguish documented capabilities from observations in a single test. A web UI does not prove API access. Do not assume a custom tool can invoke private models or access the entire asset library.
